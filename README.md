# Чат-бот — помощник студента (Tkinter)

Настольное графическое приложение **«Чат-бот — помощник студента»** на Python 3 с использованием стандартной библиотеки `tkinter` (`ScrolledText`, `Entry`, `Button`, `messagebox`). Пользователь вводит сообщение, программа распознаёт ключевые слова и выводит подготовленный ответ в области переписки.

## Возможности

- Заголовок окна и шапки интерфейса **«Чат-бот — помощник студента»**.
- Область истории переписки на основе `ScrolledText` с автопрокруткой и защитой от случайного редактирования.
- Поле ввода `Entry` с поддержкой отправки сообщения по клавише `Enter` (`<Return>` / `<KP_Enter>`).
- Кнопки управления: **«Отправить»**, **«Очистить чат»** и **«Выход»**.
- Строка состояния **«Бот готов к работе»** с индикацией предупреждений и выполненных действий.
- Защита от отправки пустых сообщений и автоматическая очистка поля ввода после отправки.
- Визуальное разделение сообщений пользователя и бота (разные цвета, фоновые выделения и отступы) и отображение текущего времени `[ЧЧ:ММ:СС]` у каждого сообщения.
- Подтверждение выхода через диалоговое окно перед закрытием приложения (как по кнопке «Выход», так и по закрытию окна).
- Распознавание **12 команд** (нечувствительность к регистру, нормализация `ё → е`, учёт границ слов и синонимов).

## Поддерживаемые команды

| № | Команда | Назначение ответа |
| --- | --- | --- |
| 1 | `Привет` | Приветствие пользователя |
| 2 | `Как дела` | Ответ о состоянии бота |
| 3 | `Расписание` | Информация о занятиях |
| 4 | `Домашнее задание` | Напоминание о заданиях |
| 5 | `Python` | Краткая информация о языке |
| 6 | `Tkinter` | Назначение библиотеки |
| 7 | `Преподаватель` | Информация о преподавателе |
| 8 | `Помощь` | Список доступных команд |
| 9 | `Спасибо` | Вежливый ответ |
| 10 | `Пока` | Прощание |
| 11 | `Экзамен` | Советы по подготовке к сессии и зачётам |
| 12 | `Время` | Текущая дата и время |

Если введённая команда не распознана, бот выводит сообщение:
> Я пока не знаю ответа на этот вопрос. Введите “Помощь”, чтобы увидеть список команд.

## Структура проекта

- `chatbot.py` — исходный код приложения (`StudentChatBot` с логикой распознавания команд и `ChatBotApp` с интерфейсом Tkinter).
- `test_chatbot.py` — автоматические модульные тесты (`unittest`), проверяющие все команды, обработку ошибок, виджеты интерфейса, клавишу `Enter`, очистку чата и подтверждение выхода.

## Запуск приложения

Требуется Python 3.10+ (библиотека `tkinter` входит в стандартную поставку Python).

```bash
python chatbot.py
```

## Запуск тестов

```bash
python -m unittest -v
```
